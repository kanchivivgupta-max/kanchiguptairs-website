# handhold

A personal portfolio website, and a learning project for getting comfortable
with Claude Code. Plain HTML, CSS, and JavaScript — no frameworks, no build
step, no npm install. Open `index.html` directly in a browser to preview.

## Files

- `index.html` — page content and structure
- `styles.css` — all styling; color/theme variables live at the top under `:root`
- `script.js` — interactive behavior (dark mode toggle, greeting, footer year)
